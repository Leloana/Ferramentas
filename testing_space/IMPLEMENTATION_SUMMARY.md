### `game.js`
**Purpose:** Core game logic and rendering
**Key Functions:**
- `initBalls()`: Sets up 15 colored balls in triangle formation + cue ball
- `initPockets()`: Defines 6 pocket positions
- `checkPot(ball)`: Detects if ball is in pocket
- `update()`: Handles physics (movement, friction, wall collision)
- `draw()`: Renders balls, pockets, cue stick, and score
- `drawCue()`: Draws the cue stick
- `calculateScore()`: Sums values of potted balls
- `shoot()`: Handles click-to-shoot mechanic
- `gameLoop()`: Main animation loop

---

### `scoring.js`
**Purpose:** Ball scoring and pocket detection utilities
**Key Data:**
- `POCKETS`: Array of 6 pocket coordinates
- `BALL_POINTS`: Point values for each ball color
- `POCKET_RADIUS`: Detection radius (30px)

**Key Functions:**
- `checkPot(ball)`: Returns point value if ball is in pocket, null otherwise
