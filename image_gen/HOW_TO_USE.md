# How to use this tool (Krea2 Turbo image generator)

Guide for an AI model (not a human) to use the `image_krea2_turbo_t2i.json`
file in this folder and generate an image from text. Follow the steps IN
ORDER. Do not skip steps, do not invent endpoints other than the ones
listed here.

## What this is

`image_krea2_turbo_t2i.json` is a **ComfyUI workflow in API format** (not
the graphical interface — it's a JSON you send over HTTP). It takes a text
prompt and returns an image generated by the `krea2_turbo` diffusion model.

Every generated image must be saved into the `resultados/` folder (same
folder as this guide). That folder already exists and is in `.gitignore` —
do not create another output folder.

## Prerequisite (mandatory, check this first)

ComfyUI must already be open and running locally. Confirm with:

```
GET http://127.0.0.1:8188/system_stats
```

If this call fails (connection refused), **stop and tell the user** — you
cannot generate an image without ComfyUI open. Do not try to "guess"
another port or server on your own.

## Step by step

1. Read the `image_krea2_turbo_t2i.json` file (it's in this same folder)
   and load it as JSON in memory.
2. Make a **copy** of that JSON in memory. Edit only the copy. **Never
   overwrite the `image_krea2_turbo_t2i.json` file on disk.**
3. In the copy, edit the fields in the table below (keys like `"30:19"`,
   `"49"`, etc. are node IDs — top-level keys of the JSON):

   | I want to change | Node | Field inside `inputs` | Type | Example |
   |---|---|---|---|---|
   | The prompt (image text) | `30:19` | `value` | string | `"a red fox sitting in the snow, forest background"` |
   | Image aspect ratio | `49` | `aspect_ratio` | string (one of the options below) | `"16:9 (Widescreen)"` |
   | Image size | `49` | `megapixels` | float, 0.1 to 16.0 | `1.0` |
   | Random seed | `30:3` | `seed` | int, 0 to 2^32-1 | a new random number for each generation |

   Valid `aspect_ratio` values (node `49`): `"1:1 (Square)"`,
   `"2:3 (Portrait Photo)"`, `"3:2 (Photo)"`, `"3:4 (Portrait Standard)"`,
   `"4:3 (Standard)"`, `"9:16 (Portrait Widescreen)"`, `"16:9 (Widescreen)"`,
   `"21:9 (Ultrawide)"`.

   Leave **every other field in the JSON exactly as it is** (including
   `30:24`, `30:23` — they default to `false`, which is the recommended
   mode; see "Optional features" at the end if you need to touch them).

4. Before sending, apply the rules in the **"Prompt rules"** section below
   to the text you put in `30:19`.
5. Send the edited copy:

   ```
   POST http://127.0.0.1:8188/prompt
   Body (JSON): {"prompt": <the whole edited JSON>}
   ```

   The response includes `"prompt_id"`. Save that value. If the response
   has a non-empty `"node_errors"` key, something in the JSON is wrong —
   stop and report the error, do not try to guess a fix.
6. Wait for the image to finish, checking every ~2 seconds:

   ```
   GET http://127.0.0.1:8188/history/<prompt_id>
   ```

   When `<prompt_id>.status.completed == true` in the response, it's done.
   If `<prompt_id>.status.status_str == "error"`, generation failed — read
   `status.messages` and stop (do not automatically keep retrying).
   Suggested timeout: 10 minutes (generation can take a while depending on
   the machine).
7. Get the generated file's data from
   `<prompt_id>.outputs["29"].images[0]` (has `filename`, `subfolder`, `type`).
8. Download the final image:

   ```
   GET http://127.0.0.1:8188/view?filename=<filename>&subfolder=<subfolder>&type=<type>
   ```

   Save the response's binary content as `.png` inside the `resultados/`
   folder (same folder as this guide). **All generated images must go into
   `resultados/`** — do not save into the root of `image_gen/` or any other
   folder. `resultados/` is in the repository's `.gitignore` (not
   version-controlled), so you can generate freely without polluting git.

## Ready-to-use Python script (copy it, change only PROMPT, and run)

```python
import copy, json, random, time, requests

SERVER = "http://127.0.0.1:8188"
WORKFLOW_PATH = "image_krea2_turbo_t2i.json"  # this file, same folder

PROMPT = "a red fox sitting in the snow, forest background"  # <-- change this
ASPECT_RATIO = "16:9 (Widescreen)"  # see valid options in the guide
OUTPUT_FILE = "resultados/output.png"  # always inside resultados/

with open(WORKFLOW_PATH, encoding="utf-8") as f:
    workflow = json.load(f)

wf = copy.deepcopy(workflow)
wf["30:19"]["inputs"]["value"] = PROMPT
wf["49"]["inputs"]["aspect_ratio"] = ASPECT_RATIO
wf["30:3"]["inputs"]["seed"] = random.randint(0, 2**32 - 1)

resp = requests.post(f"{SERVER}/prompt", json={"prompt": wf}, timeout=30)
resp.raise_for_status()
data = resp.json()
if data.get("node_errors"):
    raise RuntimeError(data["node_errors"])
prompt_id = data["prompt_id"]

entry = None
start = time.monotonic()
while time.monotonic() - start < 600:
    hist = requests.get(f"{SERVER}/history/{prompt_id}", timeout=30).json()
    entry = hist.get(prompt_id)
    if entry:
        status = entry.get("status", {})
        if status.get("status_str") == "error":
            raise RuntimeError(status.get("messages"))
        if status.get("completed"):
            break
    time.sleep(2)
else:
    raise TimeoutError("ComfyUI did not finish in time")

img = entry["outputs"]["29"]["images"][0]
r = requests.get(f"{SERVER}/view", params={
    "filename": img["filename"],
    "subfolder": img.get("subfolder", ""),
    "type": img.get("type", "output"),
}, timeout=60)
r.raise_for_status()
with open(OUTPUT_FILE, "wb") as f:
    f.write(r.content)
print(f"Image saved to {OUTPUT_FILE}")
```

## Prompt rules (mandatory — learned generating hundreds of real images)

1. **Write the prompt in English.** The model works more reliably in
   English. Do not mix other languages into the English text.
2. **If the scene has people, describe their clothing explicitly**, even if
   it seems obvious. Without this, the model tends to draw the person
   nude/partially nude by default. End the prompt with something like:
   `, fully clothed, appropriate attire, no nudity`
3. **Do not ask for text, signs, or captions in the image**, unless it's
   truly necessary. Diffusion models draw malformed ("garbled") text. If
   the scene has architecture/monuments and you want to avoid letters
   appearing on a wall by themselves, add something like:
   `, no text, no signage, no writing`
4. **Prefer `"16:9 (Widescreen)"`** when there's no requirement for a
   vertical format. Vertical formats (`9:16`, `3:4`) have a much higher
   defect rate (wrong rotation, duplicated scene panels) on this model.
5. **Write a short, concrete prompt** (one objective sentence describing
   the scene), not a long paragraph packed with simultaneous details. Long
   prompts increase hallucination (extra limbs, duplicated panels),
   especially in vertical format.
6. **Name the culture/historical period explicitly when it matters** (e.g.
   write `"ancient Greek bronze armor"`, not just `"armor"`). Without this
   the model tends to "slip" into the most generic style (e.g. medieval
   European armor) even when the prompt asks for something else. Trying to
   exclude a style won't help — this workflow has no real negative prompt
   (`cfg` is fixed at `1`, which mathematically cancels out any negative).
   The only way to avoid something is to reinforce the opposite in the
   positive prompt itself.
7. **Always check the image after it's generated.** "Finished without
   error" does not guarantee the content is correct — the model can
   occasionally ignore the whole prompt and draw something else entirely.
   If the image comes out wrong, generate again with a new seed (step 3 of
   the script already randomizes the seed on every call).
8. **If the same failure repeats 2 times in a row with the same prompt,
   stop trying new seeds — rewrite the prompt instead.** Some sentence
   constructions (e.g. "X transitioning into Y") cause failure
   consistently, not by sampling bad luck.

## Optional features (do not touch unless explicitly asked)

- **Automatic prompt refinement** (node `30:24`, field `value`): if `true`,
  a language model (`qwen3vl`, node `30:16`) rewrites your text into a
  richer description before generating the image. This can help
  short/vague prompts, but can also introduce the garbled-text problems
  described in rule 3 above (the refiner sometimes interprets declarative
  sentences as a "caption request"). File default: `false` (uses your
  literal text). Only turn it on if the user explicitly asks for it.
- **Style LoRA** (nodes `30:23`, `42`, `30:15`): applies an extra visual
  style (e.g. watercolor, pastel tones) on top of the base model. Off by
  default (`30:23.value = false`). In this environment, **only
  `krea2_warmpastel.safetensors` is confirmed installed** — the other
  options listed in node `42` (`krea2_coolblue`, `krea2_darkbrush`,
  `krea2_plasmoid`) may not exist on disk and will make generation fail.
  Do not enable this unless the user asks for a specific style.

## What each node does (quick reference — no need to memorize)

| Node | Function |
|---|---|
| `30:19` | Your prompt (input text) |
| `30:18` | System prompt for automatic refinement (only used if `30:24=true`) |
| `30:24` | Toggles automatic prompt refinement on/off |
| `30:16` | The language model that does the refinement (`qwen3vl_4b`) |
| `49` | Final image resolution/aspect ratio |
| `30:3` | Image generator (KSampler) — 8 steps, `cfg=1` ("turbo" model) |
| `30:10` / `30:11` / `30:12` | Load the diffusion, CLIP, and VAE models — do not touch |
| `30:23` / `42` / `30:15` | Optional style LoRA (off by default) |
| `29` | Saves the final image (filename prefix: `Krea2_turbo`) |
