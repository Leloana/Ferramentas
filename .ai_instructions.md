# Regras da IA Assistente

Estas instruções são carregadas automaticamente pelo seu assistente de IA como contexto para operar neste repositório.

## Fluxo de Trabalho e Controle de Versão (Git Workflow)

Este repositório possui uma regra estrita de versionamento contínuo e automatizado para evitar perda de código ou dessincronizações:

1. **Commit Automatizado e Descritivo**: Toda e qualquer alteração realizada pelo assistente de IA (Antigravity) deve obrigatoriamente ser compilada em um commit descritivo.
2. **Push Imediato**: Após realizar o commit das alterações diretamente na branch de trabalho ativa (ex: `main`), o push para o repositório remoto (`origin/main`) deve ser executado imediatamente.
3. **Divisão em Lotes (Batches)**: Ao realizar múltiplas tarefas ou tratar múltiplos componentes, as alterações devem ser agrupadas e commitadas em lotes lógicos e sequenciais, mantendo a clareza do histórico de commits.
4. **Branch Única**: Como este repositório é mantido por um único desenvolvedor, todas as alterações vão diretamente para a branch de trabalho atual, sem a necessidade de criação de branches de feature adicionais.

## Estrutura do Projeto
1. **Nova Ferramenta**: Todo novo script ou aplicação deve obrigatoriamente seguir a arquitetura `raiz -> pasta_da_ferramenta -> ferramenta_em_si`. 
   - Exemplo: `C:\Users\mf827\Desktop\GUARDAR\Ferramentas\nome_da_nova_ferramenta\main.py`
   - Nunca criar arquivos soltos na raiz (com exceção de `README.md`, `.gitignore`, `.ai_instructions.md`, etc.).

2. Em caso de bibliotecas python gerar venv
