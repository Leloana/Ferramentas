# Regras da IA Assistente

Estas instruções são carregadas automaticamente pelo seu assistente de IA como contexto para operar neste repositório.

## Fluxo de Trabalho (Git Workflow)
1. **Nova Feature Concluída**: Sempre que finalizar o desenvolvimento de uma nova feature ou correção significativa, você (a IA) deverá:
   - Fazer o stage dos arquivos modificados: `git add .`
   - Realizar o commit adotando boas práticas com uma mensagem clara diretamente na branch atual (ex: main): `git commit -m "feat: descrição da feature"`
   - Fazer o push da alteração: `git push`
   - *Nota*: Como este repositório é mantido por um único desenvolvedor, **não** há necessidade de criar novas branches de feature. Tudo deve ir direto para a branch de trabalho atual.
